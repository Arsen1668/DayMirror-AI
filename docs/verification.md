## 自动测试

新增验证：新会话两轮所有问题文本为空；第一题未保存时回答和跳过均被拒绝且磁盘不变；只允许生成当前题，不允许提前生成后续题；基础题也有幂等和不可替换保护；动态基础题在新进程恢复时保持原文。旧版预填基础题的会话仍可恢复，原问题与原回答保留。

原有验证覆盖 20 题完成与导出、跳过、未知评分、部分日记继续、答案修正、旧版保留、来源引用、中文换行、重试、文件锁、原子写入失败和固定白名单私密排除。选项字母原话及完整问题可导出，指标不会自动填值。

## 合成演示

demo 在 47 个独立 Python 子进程中逐题保存问题，再回答、暂停并退出、从第 4 题原文恢复、完成全部槽位并保存。18 题回答、2 题跳过；重复保存幂等，压力保持 null。

合成问答仅前三题给选项，随后采用开放式提问；内容从写作、阅读和学习转向身体、散步、晚间生活与反思。示例并非真实模型生成或固定访谈题库，可查看 [合成日记](../daymirror/assets/example-journal.md)。

## 提问质量边界

自动测试验证 Python 的持久化、兼容性与分发，不证明 AI 实际提问的多样性、上下文理解或一天覆盖程度。新版 Skill 规定上一回答优先、时间线与生活场景覆盖、开场 3–5 题选项，以及之后的具体开放式追问；这些对话效果仍需真实客户端试用核对。
