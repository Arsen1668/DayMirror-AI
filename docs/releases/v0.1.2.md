# DayMirror v0.1.2 — Attribution and citation

Status: prepared locally. This document does not announce an already published GitHub Release or a registered DOI.

## Release body

DayMirror now makes its project origin and official source easier to identify. Created and maintained by [Arsen1668](https://github.com/Arsen1668), with AI-assisted implementation.

This release adds citation metadata, a design-origin record, a changelog, and explicit attribution in the standalone Skill. MIT reuse permissions remain in place. The guided interview improvements from v0.1.1 remain included: a gentler opening, optional choices, and questions that build on the user's answers.

The interview storage format remains schema version 1. Existing sessions retain their saved questions, answers, and progress.

Validation: see [the verification report](../verification.md) for actual checks. Attribution records identify this project's source and history; they do not establish global first-invention or exclusive ownership of an idea.

## Publish this version

1. Upload the updated public source files to the repository root, preserving subdirectories and including the root CITATION.cff. Keep personal records, work directories, and build outputs out of the source upload.
2. On GitHub, open Releases and create a release with a new tag v0.1.2, targeting the updated main branch. Use the Release body section above as the description.
3. Attach outputs/daymirror-v0.1.2.zip and its manifest, then publish the release.
4. After publication, use the actual release date in both CITATION.cff files if adding date-released, and update the changelog's publication status. Do not backdate a release.

For an optional persistent archive, configure the public repository's Zenodo integration before publishing the release. Add a DOI only after Zenodo has actually issued one. See [GitHub's archiving guidance](https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content).

Creating the GitHub release or authorizing Zenodo is a separate external action; this local preparation has not performed either.
