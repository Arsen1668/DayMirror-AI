# DayMirror v0.1.3 — Adaptive interviews

Status: prepared locally; no GitHub Release or DOI registration has been performed by this update.

## Release body

DayMirror now generates both interview rounds one question at a time from the user's answers. New sessions have no prefilled question bank. Every next question is chosen after reading the latest transcript, using the previous answer as an entry point while checking which parts of the day remain unexplored.

Answer choices help with the first three questions and may continue through question five when the user needs more support. Later questions use concrete, open-ended follow-ups. Time periods and life contexts guide coverage without imposing a fixed topic order or focusing the entire interview on one work task.

Questions are still saved before display. Pause and resume preserve the exact pending question; older sessions retain their saved questions and answers. The two-round 10+10 progress structure and schema version 1 remain compatible.

The synthetic demo illustrates choices on questions 1–3 and open-ended questions afterward. It verifies storage and recovery, rather than model interview quality. See [verification](../verification.md) for actual results.
