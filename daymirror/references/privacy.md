# 本地存储与模型处理

DayMirror 的 JSON 问答、进度、临时输入和 Markdown 日记保存为用户工作空间中的明文文件。Python 工具不调用模型 API，不包含联网、上传或遥测逻辑，也不存储 API 密钥。

使用 AI 客户端采访时，用户回答、客户端读取的会话内容与总结可能由该客户端发送给云端模型。是否发送、留存多久及是否用于其他用途，取决于客户端和模型服务设置。本地保存不意味着本地推理，也不能保证从聊天记录或服务端删除内容。

首次开始个人回答前可说明：

> 我会把问答和日记保存到你选择的本地工作空间。文件是明文；当前 AI 客户端可能将对话和读取的内容发送给模型服务，DayMirror 的 Python 工具本身不会联网。你可以跳过、暂停或提前结束。

默认工作空间是项目内 private/workspace。另选目录时，用户应知道是否处于网盘同步、共享目录或公共代码仓库中；Skill 不主动搬运或上传记录。

本项目的 .gitignore 排除 private、work、outputs 和缓存。分发包采用固定文件白名单，不依赖 .gitignore 判断是否包含私人数据。公开的合成问答明确标注 synthetic，不包含真实个人经历。

用户可以删除自己选定工作空间中的会话、输入文件和导出日记；删除某份 Markdown 不会同步删除 JSON 或其他版本。工具没有远端删除能力。v0.1 不提供加密、身份认证、云端同步或历史自动读取。
